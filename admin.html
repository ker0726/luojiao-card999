还差一步：把站点连到你的 Supabase

后台和站点共用一个配置项。填好之后这套后台就能直接改内容了。

  1. 注册 supabase.com，新建一个项目（Region 选 Singapore 更快）。
  2. 左侧 SQL Editor → New query，把 supabase/schema.sql 全文粘贴进去 → Run。
  3. Project Settings → API，复制 Project URL 和 anon public key。
  4. 把这两个值填进 js/supabase-config.js 的 url 与 anonKey，重新部署一次。
  5. Authentication → Users → Add user，建一个管理员邮箱+密码（关掉邮件确认更快）。

也可以把 URL 与 anon key 发给 AI 助手，让它帮你填好并部署。
